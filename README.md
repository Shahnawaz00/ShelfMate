# ShelfMate - Android Reading Tracker

ShelfMate is a native Android app developed in Kotlin designed to help users track their reading progress and manage personal book collections efficiently. The app provides a simple, intuitive interface for adding books, updating reading status, and taking notes.

## Key Features
- Add and edit book entries with title, author, and progress status
- Persist data locally using SharedPreferences for offline access
- Responsive UI supporting portrait and landscape modes
- Clean architecture with emphasis on lifecycle management and state persistence

## Technologies Used
- Kotlin
- Android Studio
- SharedPreferences
- MVVM architectural pattern 

## Getting Started
To build and run the app, clone the repo and open it in Android Studio. Build the project and install it on an emulator or device.
